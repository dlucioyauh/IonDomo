## 1. Introdução

O **IonDomo** é uma solução de controle parental e bem-estar digital desenvolvida pela **IONKOD**, projetada para ajudar pais e responsáveis a monitorar e gerenciar o uso de dispositivos digitais por crianças e adolescentes.

Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos os dados pessoais, com especial atenção aos dados de crianças e adolescentes, em conformidade com a **Lei Geral de Proteção de Dados (LGPD)**.

## 2. Dados Coletados

### 2.1 Dados do Responsável Legal
- Nome completo
- E-mail
- Telefone
- CPF (para verificação de identidade)

### 2.2 Dados da Criança/Adolescente (Art. 14 LGPD)
- Nome (ou pseudônimo)
- Idade
- Dados de uso do dispositivo:
  - Aplicativos utilizados
  - Tempo de uso por aplicativo
  - Horários de uso
  - Metadados de notificações (remetente, timestamp)
  - URLs visitadas (para filtragem de conteúdo)

### 2.3 Dados NÃO Coletados
- Conteúdo completo de mensagens (WhatsApp, SMS, etc.)
- Senhas
- Dados biométricos
- Localização precisa em tempo real (a menos que explicitamente autorizado)

## 3. Base Legal para Tratamento (Art. 7º e 14 LGPD)

O tratamento de dados de crianças e adolescentes é realizado com base em:

1. **Consentimento parental explícito** (Art. 14, §1º): Coletamos o consentimento específico e destacado de pelo menos um dos pais ou responsável legal.

2. **Melhor interesse da criança** (Art. 14, caput): O tratamento é realizado exclusivamente para proteger a criança e promover seu bem-estar digital.

3. **Legítimo interesse** (Art. 7º, IX): Para garantir a segurança da plataforma e prevenir fraudes.

## 4. Finalidade do Tratamento

Os dados são coletados exclusivamente para:

1. **Monitoramento parental**: Permitir que os responsáveis acompanhem o uso digital das crianças.
2. **Filtragem de conteúdo**: Bloquear acesso a conteúdo inadequado.
3. **Limites de tempo**: Configurar e aplicar limites de uso de dispositivos.
4. **Relatórios de bem-estar digital**: Gerar insights sobre hábitos digitais.
5. **Segurança**: Proteger a plataforma contra acessos não autorizados.

## 5. Compartilhamento de Dados

**NÃO compartilhamos dados de crianças e adolescentes com terceiros**, exceto:

1. Quando exigido por lei ou ordem judicial.
2. Para proteger a segurança da criança em situações de risco.
3. Com prestadores de serviço essenciais (hospedagem, e-mail) que seguem nossos padrões de segurança.

## 6. Retenção de Dados

- Dados de uso: Retidos por **90 dias** e anonimizados após esse período.
- Dados cadastrais: Retidos enquanto a conta estiver ativa.
- Após solicitação de exclusão: Dados eliminados em até **30 dias**.

## 7. Direitos dos Titulares (Art. 18 LGPD)

Os pais/responsáveis têm direito a:

1. **Acesso**: Solicitar cópia de todos os dados coletados.
2. **Correção**: Corrigir dados incompletos ou incorretos.
3. **Exclusão**: Solicitar a eliminação dos dados (direito ao esquecimento).
4. **Portabilidade**: Exportar os dados em formato estruturado.
5. **Revogação do consentimento**: Retirar o consentimento a qualquer momento.

## 8. Segurança dos Dados

Implementamos as seguintes medidas de segurança:

1. **Criptografia de ponta a ponta** (AES-256-GCM + RSA-2048)
2. **Armazenamento criptografado** (EncryptedSharedPreferences)
3. **Autenticação multifator** (MFA) para contas de responsáveis
4. **Auditoria de acesso** (logs imutáveis)
5. **Anonimização** de dados para análise

## 9. Transferência Internacional de Dados

Os dados são armazenados em servidores localizados no **Brasil**. Caso haja necessidade de transferência internacional, garantiremos o mesmo nível de proteção exigido pela LGPD.
